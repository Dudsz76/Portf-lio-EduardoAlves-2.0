## Projeto 1-Predição de Churn em Telecom

> *"Antecipar para reter: identificando clientes em risco antes que eles partam."*

Pipeline completo de Machine Learning para prever o risco de cancelamento (churn) de clientes de telecom, com API própria e dashboard interativo para o time de vendas.

### O Contexto:
A empresa perde ~25% dos clientes por ano. Reter um cliente custa, em média, 5x menos do que adquirir um novo. Este projeto identifica clientes com alto risco de cancelamento nos próximos meses, permitindo ações de retenção proativas em vez de reativas.

**Categoria:** Ciência de Dados & Machine Learning  
**Tecnologias:** Python, Scikit-learn, Pandas, FastAPI, Streamlit 
Capacitar o time de vendas com dados acionáveis, permitindo **ações de retenção proativas** – abordando clientes em risco antes que decidam cancelar, não depois.

## 📓 Agenda para Pessoas Neurodivergentes

> *"Foco sem culpa: uma agenda que respeita seu jeito único de funcionar."*

**Categoria:** Desenvolvimento de Aplicativos  
**Tecnologias:** Python, PyQT6, JSON, Sys, OS

### O Contexto
Pessoas neurodivergentes frequentemente enfrentam desafios com **organização, transições entre tarefas e sobrecarga sensorial**. Este aplicativo foi criado com empatia e baseado em métodos comprovados para facilitar a atenção e reduzir a ansiedade.

### Funcionalidades Pensadas com Carinho
- 🎨 **Cards coloridos deslizáveis** com significado fixo:
  - 🔵 **Azul** = Atividades para fazer sozinho
  - 🟢 **Verde** = Tarefas prazerosas
  - 🟡 **Amarelo** = Momentos de transição
  - 🔴 **Vermelho** = Compromissos sociais
  - 🟣 **Roxo** = Surpresas/Imprevistos

- 🚂 **Modo "Trem"** – uma abordagem lúdica para manter o foco
- 💬 **Lembretes educados "Sem Culpa"** – um sistema que incentiva, não cobra

### Tecnologia com Propósito
Este protótipo foi desenvolvido com **vibe coding**, unindo agilidade no desenvolvimento com um olhar atento às necessidades reais dos usuários.
